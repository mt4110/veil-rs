# M2: 公開CLI helpの日英対応

## 目的

Rustなしの導入後、初回スキャン・ステージ点検・次回利用へhelpから進めるようにする。0.22.0のM2を対象とし、M3の英語チュートリアルや公開判断は含めない。

## 変更

- 公開19画面の説明・引数・見出し・具体例・必要な注意を静的な日英カタログへ集約。
- `--lang`、VEIL_LANG、localeの優先順位を定義。引数解析と同じ定義の非実行probeで表示言語だけを選び、実行は厳密な解析結果だけを使用。
- 通常help・helpサブコマンド・引数なしhelpの定義を共通化。機械出力・検査ロジック・終了コード・隠しコマンドの公開範囲は保持。
- インストーラーの版確認は環境のCLI言語に依存させず、明示した導入言語を妨げない。
- 日英の導入文書に公開済み0.21.0と開発候補の区別を追記。版番号・公開済み成果物は保持。

## 検証

- 公開command/argumentの翻訳漏れ、19画面のJA/EN、短いhelp、各help経路、不正言語・locale・引数値と`--`境界を検査。
- 壊れた設定・Git外でもhelpが副作用なしで成功することを確認。合成データの検出・秘匿・JSON契約・終了0/1/2を確認。
- 英語snapshotを明示言語で固定。CLI回帰、導入回帰、両OSのネイティブ実行と更新headのCIを確認する。
- 両OSの結果はPR本文・Checksへ記録する。限定検証を実開発での継続利用実績と扱わない。

マージ・タグpush・Release公開・X投稿は行わない。macOS配布のad-hoc署名制限は保持する。
