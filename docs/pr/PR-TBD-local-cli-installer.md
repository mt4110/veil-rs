# M1: 展開ZIPからのローカル導入

## 目的

利用者がRustなしでCLIを導入し、次のターミナルでも意図した版を呼べるようにする。初回・commit前・次回利用という既存導線に接続する。

## 変更

- ZIPに `install.sh` と日英の導入・PATH・復帰ガイドを明示同梱し、内部SHA256SUMSの対象へ追加。
- prefix配下へ版別packetを保持。checksum・OS/CPUとコピー後の検証を経て呼出先を作成する。
- 同じ版の再実行、既存CLIとの衝突拒否、管理内の別版への明示切替・復帰、失敗時の既存CLI保全を定義。
- dotfile自動編集・sudo・通信・Rust・自動更新・旧版掃除を追加しない。CLI helpの日英化はM2であり今回の範囲外。
- 版番号と公開済み0.21.0/rc.4は保持。新しい候補にだけスクリプトを含める。

## 検証

- ネイティブfixture実行ファイルでの回帰と、CIの実CLI最終ZIPを展開した導入検査を分離する。
- 正常・再実行・管理内切替/復帰・管理外/通常/破損リンク・checksum・コピー途中/破損・切替失敗・書込み不能・空白と引用符のprefix・OS/CPU不一致を検査。
- 新しいbash/zshプロセスと隔離したPATH・シェル設定で確認。インストーラーのPATHにcargo/rustc/cc/curl/sudoを含めない。
- 配布allowlist、ライセンス、文書分類、依存境界、SOTと更新head CIを確認する。両OSの実CLI候補ZIPからの確認結果はChecksと検証記録を参照。

macOSのad-hoc署名制限とダウンロード後Gatekeeper未検証、実開発での継続利用未確認は保持する。今回の導入検査を実利用実績と扱わない。
