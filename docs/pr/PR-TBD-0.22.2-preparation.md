# CLI 0.22.2 の配布準備

## SOT

- 対象は `feat/release-v0.22.2`。ベースは `main` の `e4ee219`。

## What

- CLI・Core・Config・LSP のバージョンを 0.22.2 に揃え、Cargo ワークスペースと fuzz ワークスペースのロックファイル、Nix の CLI パッケージ、第三者ライセンス台帳の Cargo.lock ハッシュを更新する。

## Verification

- Rust 1.92.0 で両 Cargo ワークスペースのロックファイルを検証した。CLI 配布ガードと関連テスト24件、fmt、文書分類が通過し、Nix の CLI パッケージは 0.22.2 と評価された。
- macOS arm64 でネイティブビルドし、ZIP 展開後の起動、インストール21件、ステージ済み内容の検査、日英の初回利用を確認した。
- Linux x86_64 musl 向けにクロスビルドし、静的リンクと ZIP 展開後の起動を確認した。Colima の x86_64 エミュレーションでインストール20件が通り、root ではスキップされた権限拒否の1件も非 root で通過した。ステージ済み内容の検査と日英の初回利用も通過した。Linux x86_64 のネイティブ実行は未確認。
- 2本の ZIP の SHA-256 を照合し、配布チェックのソースフィンガープリントが両環境で一致することを確認した。
