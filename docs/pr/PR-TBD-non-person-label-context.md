# 開発時の氏名・会員IDの誤検出を限定修正

## SOT
- Status: Draft
- Goal: 実際の個人情報の点検を維持し、実開発で不要な判断負担を減らす。
- Scope: 氏名・顧客／会員IDの2件のみ。版番号・公開済み成果物は変更しない。

## What
- 小文字のポート／名前マッピングの説明文を、後続の人物ラベルを保持して除外する。
- Rustの限定的なmatches!式内のOS UIDアクセサーをID値と区別する。
- 架空データによる再現・境界・通常の個人情報・IPv4維持の回帰検査を追加する。
- 元リポジトリのコード・検出値・パス・検査出力は記録しない。

## Verification
- 修正前のソースで2つの新規再現テストが失敗することを確認。
- macOS ARM64: `cargo +1.92.0 test --locked --offline -p veil-core`。
- Linux x86_64 musl: 同じ回帰テストをRust1.92.0で実行。CPUQuota=50%、MemoryMax=4G、1ビルドジョブで制限。
- 通常の氏名・日英ID、引用符付き値、同じ行の別ラベル、テストIPv4を保持する。
- Draft PRのCIはhead更新後の全チェック成功を完了条件とする。

## Evidence
- 架空データのみをテストに保存。実作業データの再検査は別インデックスとメモリ内集計で行い、検出値は保存しない。
- 両OS検証とCIの最終結果はPR本文に記録する。

## Non-goals
- テスト用IPv4の一律除外、全般的な検知基準の緩和、依存追加。
- 既存変更・通常のCrossportインデックスへの操作、マージ・タグ・Release公開。
