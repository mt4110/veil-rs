# Security Policy

## Supported versions

Use the [latest stable release](https://github.com/mt4110/veil-rs/releases/latest)
when possible. Reports about older versions are welcome. Include the version
or commit you tested so we can identify the affected versions.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mt4110/veil-rs/security/advisories/new)
to contact the maintainers. Please keep suspected vulnerabilities out of
public issues and pull requests while we investigate.

Include the affected version or commit, the observed impact, and steps to
reproduce the issue. Use sanitized examples and omit credentials or personal
data. Mention any workaround you have found.

We aim to acknowledge good-faith reports within five business days and to
coordinate a fix and release before public disclosure when practical.
